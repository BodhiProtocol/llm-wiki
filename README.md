# LLM Wiki

**24 core LLM/AI concepts across 6 categories — tokens, prompting, RAG, embeddings, agents, MCP, and more. Search, category filters, dark/light mode.**

Live demo → https://bodhiprotocol.github.io/llm-wiki/

---

## Why this exists

Working with LLMs day to day means hearing "tokens," "RAG," "embeddings," and "agents" thrown around constantly — often without a clear, plain-language anchor for what each term actually means or why it matters in practice.

This is a compact reference: one card per concept, a plain-language explanation, and an expandable "why it matters" note — built for quick lookups, not a textbook read-through.

## What's inside

- 24 LLM/AI concept cards across 6 categories
- Search bar + category chip filters
- "Surprise me" button for random exploration
- Expandable "why it matters" note per card
- Copy-link deep linking to any individual term

## Tech

One self-contained `index.html`. No frameworks, no build step, no API calls. Dark/light theme toggle. Data lives in a single in-file JS array — no database, manual edits only.
